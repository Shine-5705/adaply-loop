Adaply Loop
How it worksCLIGitHub

Your coding agent should only need to be told once.

Drop in Claude Code or Codex session logs. Adaply Loop finds the corrections you keep repeating across sessions, gates them, and writes them into AGENTS.md so every agent on the team gets them. Everything runs in this tab; nothing is uploaded.

Drop session logs here — ~/.claude/projects/**/*.jsonl or ~/.codex/sessions/**/rollout-*.jsonl
01Capture

Reads Claude Code and Codex logs. Secrets and emails are redacted locally first.

02Find

Spots user turns that correct the agent: “no, use…”, “don't…”, “I said…”.

03Cluster

Groups the same correction across sessions, repos and harnesses.

04Gate

Adopts a rule only if it recurs in 2+ sessions and doesn't duplicate or contradict AGENTS.md. Replay testing: in progress.

05Ship

Writes a versioned block to AGENTS.md. One command rolls it back.

Run it on your own machine

# zero dependencies, Node 18+ git clone https://github.com/Shine-5705/adaply-loop && cd adaply-loop node bin/adaply-loop.mjs scan # reads ~/.claude/projects and ~/.codex/sessions node bin/adaply-loop.mjs apply --repo ~/code/my-app # writes AGENTS.md, versioned in .adaply/ node bin/adaply-loop.mjs rollback --repo ~/code/my-app
