How it works

From “no, use pnpm” to a rule your agents keep.

Three steps, all on your machine. Nothing is adopted until it has come up in more than one session.

01

Read your logs

Parses Claude Code and Codex session files where they already live. Tool output and injected context are skipped; secrets are redacted first.

~/.claude/projects/**/*.jsonl
~/.codex/sessions/**/rollout-*.jsonl
✓ 6 sessions · 1 secret redacted
02

Find repeated corrections

Spots turns where you corrected the agent and groups the same correction across sessions, repos and tools.

R01 Use pnpm instead of npm   3×
R03 Never edit src/gen by hand 2×
R05 Use theme tokens          1× hold
03

Write versioned rules

Rules that recur, and don't duplicate or contradict what you have, go into a marked block in AGENTS.md. Every apply is a version you can roll back.

+ - Use pnpm instead of npm.
+ - Never edit files in src/gen by hand.
$ adaply-loop rollback  ✓ v1

Features

Built for teams that ship with agents.

Small, inspectable and boring in the right places.

Cross-harness clustering

The same correction given to Claude Code on Monday and Codex on Friday counts as one rule.

Recurrence gate

One-off remarks are held. A rule must come up in two or more separate sessions to be adopted.

Conflict and duplicate checks

Proposed rules are compared against your existing AGENTS.md so nothing contradicts what you wrote by hand.

Versions and rollback

Each apply is stored in .adaply/versions with the previous file and the evidence. One command undoes it.

Evidence for every rule

Every learned rule links back to the exact messages, files and timestamps it came from.

CLI and browser, one engine

A single dependency-free module powers both the command line and the in-browser workspace.

Docs · Quick start

Running in under a minute.

Node 18 or newer. No install step, no network calls, no telemetry.

  • scan finds recurring corrections in your logs
  • propose prints the AGENTS.md block it would write
  • apply / rollback / log manage versions

Privacy

Your logs never leave your machine.

Session logs are full of keys and customer data. Adaply Loop redacts API keys, GitHub and Slack tokens, AWS keys, bearer tokens, passwords and email addresses before anything is analyzed or stored. The browser demo processes files inside the tab; nothing is uploaded.

  • No server, no account, no telemetry
  • Evidence stored redacted, in your repo
  • MIT licensed, read every line
